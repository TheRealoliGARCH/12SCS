# Unit-test prerequisite reconstruction

The unit-test workflow reconstructs generated Phase II artifacts before running the full test suite.

The dependency chain is:

1. `run_gap_priority.py`
2. `run_active_set_breakpoints.py`
3. `run_active_set_regimes.py`
4. `run_active_set_regime_formulas.py`
5. `run_primitive_coefficient_map.py`
6. `run_primitive_counterfactual_coefficient_map.py`
7. `python -m unittest discover -s tests -p 'test_*.py' -v`

This prevents tests from depending on artifacts generated by a previous workflow run or a developer's working directory.
