# Fine-grid convergence sensitivity characterization

The sensitivity experiment evaluates the deterministic constrained allocator on
$\lambda=0,0.05,\ldots,1$, blending the homogeneous benchmark with the abstract
heterogeneous feasibility and cost matrices.

Define

$$H(\lambda)=\Pi(\lambda)/\Pi(0).$$

The workflow records the response grid, first differences, second differences,
and a descriptive curvature classification. The classification is empirical
for this benchmark; it is not a general theorem about the allocator.
